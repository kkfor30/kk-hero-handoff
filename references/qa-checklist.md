# 验证与故障定位

执行 Skill 自带的技术测试：

    node --test tests/runtime.test.mjs
    python -X utf8 -B tests/test_media.py

这些测试模拟媒体和 DOM 生命周期，并用临时合成媒体检查抽帧/版本关系，不代表浏览器视觉通过。
网站项目还应完成相称的语法、构建、资源存在性检查。遵守项目对浏览器操作的约定。

## 用户实际验收

- 首次进入没有先显示全页面再消失；视频加载失败仍能恢复静态页面。
- 居中画面未拉伸，主体没有不合理放大或被裁切。
- 回位时文字同步出现；视频结束没有额外长停顿。
- 尾帧与原图接管没有明显重影、色差或矩形边缘。
- 页面缩放、滚动及移动端横竖屏变化后，回位位置仍正确。
- 重播、只播放一次、减弱动态、跳过能按预期工作。

## 定位顺序

1. 位置跳：检查目标元素实际内容区域、容器留白和 object-fit。
2. 画面跳：对比接管帧和高清图，再查蒙版、滤镜、颜色与背景。
3. 节奏顿：核对 handoffTime、回位提前量、文字显示时间，不盲目拉长淡出。
4. 黑屏：检查加载/解码、媒体格式、初始化防闪超时。
5. 不播放：区分 session 已播、减弱动态、自动播放失败与资源错误。
6. 动作不满意但接缝正常：修改视频动作，不重做已正确的页面布局。

报告使用“规格通过/自动化通过/等待用户视觉确认”，不要统一写成“无缝通过”。
